- `actions/externalCalendars.ts`: fetchExternalCalendarData (sources+events, sources Date→ISO via serializeSource; events are TEXT start/end already); addExternalCalendarSource (normalizeIcsUrl; Google share-link cid → connected-API source else public basic.ics fallback; `fetchIcsText`: 15s abort, 10MB char cap, must match VCALENDAR, HTML-page detection message; **wart: creates ICS source row before parsing — parse throw orphans it** (API-kind creators pre-mint uuid + fetch first; fix in port)); refreshExternalCalendarSource (per kind: GOOGLE via stored refreshToken→access token; MICROSOFT via `getMicrosoftAccessTokenForUser` which **persists the rotated refresh token when changed**; ICS re-fetch; wholesale replace events in one txn + `lastFetchedAt=now,lastError=null`; **failure writes lastError and returns the updated source row with the error** — endpoint must carry the same error-with-body shape); updateExternalCalendarSource (patch name/color/mode/enabled/locationId); deleteExternalCalendarSource (deleteMany, cascade); toggleExternalEventBusyException (modeExceptions JSON string[] toggle; empty→null); setExternalEventLocation ({inherit}|{locationId} over locationExceptions JSON record; empty→null).
- `actions/googleCalendar.ts`: status/list(min freeBusyReader, paginated)/add (dup guard "`name` is already connected")/disconnect (revokeGoogleToken best-effort → `revoked:boolean` in response; txn deletes GOOGLE sources + connection; returns removedSourceIds).
