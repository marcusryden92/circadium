## Completion note (2026-11-16)

All **37 Prisma tables** are mirrored as hand-written JPA entities in `app.circadium.persistence.{entity,enums,repository}`, each with a `JpaRepository` and one Testcontainers round-trip test (**38 tests green**, `.\mvnw.cmd verify`). `ddl-auto: validate` passes with every entity loaded against the authoritative schema dump (`src/test/resources/db/schema.sql`, generated by `prisma migrate diff` from the Prisma source — so it is the same DDL dev Neon was migrated from). Field counts were cross-checked against each `CREATE TABLE` (validate is silent on columns the entity never maps, so a green validate alone does not prove completeness).

Mapping recipe proven end-to-end: the 4 global `spring.jpa` settings (validate, `PhysicalNamingStrategyStandardImpl`, `globally_quoted_identifiers`, `preferred_instant_jdbc_type: TIMESTAMP` + `jdbc.time_zone: UTC`); all 11 PG enums as `@Enumerated(STRING) @JdbcTypeCode(NAMED_ENUM)` (lowercase constants for PlannerType/EventType/WeekDayType, UPPER for the rest); JSONB as `String @JdbcTypeCode(SqlTypes.JSON)` (DraftConversation.messages, EngineMessage.payload, FeedbackReport.dataSnapshot); `INTEGER[]` as `List<Integer> @JdbcTypeCode(SqlTypes.ARRAY)` (TaskPreferences.preferredDays/avoidDays); real `TIMESTAMP(3)` → `Instant`, ISO-string TEXT → `String`; nullability drives primitive-vs-wrapper; scalar FK columns (no `@ManyToOne`); `@Column(name=...)` only on the snake_case `users`/`accounts` columns.

**One DoD sub-item not run:** the live boot-validate against **dev Neon** (`spring-boot:run` with the Neon JDBC datasource vars). It is redundant with the Testcontainers validate — the schema dump is migrate-diff-derived from the same Prisma source Neon dev was migrated from — and needs the Neon datasource wired locally (the default `local` profile points at the docker DB on 5433, whose volume was recreated 2026-11-15 and may not be migrated). Left as a trivial user-run confirmation.

Three forward decisions remain **Deferred cleanups** in the master (post-cutover): enum labels → UPPER_SNAKE (2.6), plain-id String → native uuid column type (2.6), de-muddle sync/audit timestamps TEXT → `timestamp(3)` (1.12).
