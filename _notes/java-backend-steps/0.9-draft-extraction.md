# 0.9 draft/ extraction

**Status:** ☑ Done · Phase 0 · cross-cutting context in [../java-backend-plan.md](../java-backend-plan.md)

**Task:** `utils/draft` incl. `assistantEngine` with injectable Anthropic client factory.

**DoD:** gate green; assistant turn streams in web.

**Outcome / notes:** The whole draft domain moved to `client/shared/src/draft/`: the 29 top-level pure modules (`plannerForestToJson`/`plannerTreeToJson`, `draft{Forest,Template,Window,Precedence,Habit}Ops`, `diffDraft*`, `applyDraft*`, `normalize/merge/assignDraftIds`, `draftRelocations`, `draftSettings`) plus `assistantEngine/` (the tool-use loop, `systemPrompt`, `tools`, `promptContext`, `caching`, `eventDispatch`, `turnState`, `helpers`, `constants`, `types`, and the `handlers/` domain group). Web keeps a one-line re-export shim at every old `@/utils/draft/*` path (and `@/utils/draft/assistantEngine`), so the ~many import sites (components/draft, hooks/useAIDraftState, actions/habits, the `__tests__/draft/*` suites) are untouched. **Injectable Anthropic client:** the browser BYOK client (`anthropicClient.ts` — `dangerouslyAllowBrowser` + the CORS header) is web-only and STAYS in web; the shared loop no longer imports it. `RunAssistantTurnArgs` now carries `createClient: AnthropicClientFactory` ((apiKey, baseURL?) => Anthropic), host-injected — the managed-mode seam rides its `baseURL` arg. `AIDraftModal` dynamically imports both the shared barrel AND the web `anthropicClient` in parallel and passes `createBrowserAnthropicClient` as `createClient`, keeping the SDK out of the shell bundle exactly as before. Four small pure deps were extracted alongside (web shims left behind): `plannerPriority` → `shared/domain/plannerPriority`, `isHexColor` → `shared/domain/calendarColors` (beside `fallbackCalendarColor`; web `colorUtils` re-exports it), `orderedWeekDays`/`normalizeWeekStartDay` → new `shared/domain/weekdays` (web `calendarUtils` re-exports them), and the `aiModels` lineup + `resolveAiModel` → `shared/draft/assistantEngine/aiModels` (web `lib/aiModels` shim). The assistantEngine barrel is a SIBLING file `src/draft/assistantEngine.ts` (not a dir `index.ts`), matching the `contracts.ts`-beside-`contracts/` convention — the package exports map `"./*": "./src/*.ts"` resolves a subpath to a file, never a directory index. `@anthropic-ai/sdk` + `partial-json` added to shared deps; `runAssistantTurn` dropped its `"use client"` directive (platform-agnostic; the web dynamic import already sits inside a client component). The draft tests stay in web and exercise the shared code through the shims; the `assistantEngine` scripted-stream test now passes the mocked client as `createClient` instead of relying on an internal import.

**DEFERRED:** the live BYOK assistant-turn stream in the browser (needs a real user key; held for the same merge window as 0.1's prod steps / 0.5 / 0.7 / 0.8 browser smokes) — the loop mechanics (text streaming, deterministic-op execution, tool_result feedback, onDone) are covered by the scripted-stream unit test in lieu.
